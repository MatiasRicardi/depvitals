# Security policy

## Supported versions

Security fixes are provided for the DepVitals 0.4.x series. Install the latest patch in that
series to receive available fixes.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/MatiasRicardi/depvitals/security/advisories/new)
when private reporting is enabled. Include the affected version, a minimal reproduction and the
impact. Remove credentials and private project data.

If GitHub does not offer the private reporting form, private reporting has not been enabled.
Keep vulnerability details out of public issues and pull requests.
