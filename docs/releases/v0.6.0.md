# DepVitals v0.6.0 release notes draft

These notes describe the development build targeting v0.6.0. Before publication, follow
the [local tarball instructions](../examples/ci/README.md#pre-release-local-consumer).
The examples below use `depvitals` on your PATH. DepVitals requires Node.js **22.13.0 or newer**.

## Scanner fixes and TypeScript configuration evidence

The scanner preserves real references in division expressions after JavaScript member access.
It keeps regex text inert after supported `break`, `continue` and `debugger` statements and
TypeScript declaration boundaries. JavaScript source also recognizes paired Unicode JSX tags.

An explicit package selector in the selected root's exact `tsconfig.json` can now count as
usage. The reader accepts UTF-8 JSONC with an optional BOM, comments and trailing commas.
The top-level `extends` must be a string or an array of strings. The selector must match an
exact package root declared in the selected manifest. Its original decoded value and
`/extends` or `/extends/<index>` pointer appear in `--explain`.

```sh
depvitals ./project --format json --diagnostics
depvitals ./project --format json --explain @scope/shared
```

A selected but unusable config adds the final `tsconfig-skipped` notice to completed
diagnostic scans. The notice leaves findings and scan status alone. A mandatory failure
still exits 1 with empty stdout and a diagnostic on stderr. DepVitals leaves inheritance,
other configs, path aliases and ambient type inference uninterpreted. See the
[root TypeScript configuration rules](../reference.md#root-typescript-configuration)
for the supported shape, an example and the exact evidence rules.

## JSON and CI upgrade

Every completed JSON scan and explanation declares `schemaVersion: 2`. Validate against
the [installed v2 schema and semantic rules](../../schemas/README.md#report-v2-semantic-contract).
The old v1 verifier rejects v2 reports. For v1 consumers, pin `depvitals@0.5.0` and keep
its [tagged recipe](https://github.com/MatiasRicardi/depvitals/tree/v0.5.0/docs/examples/ci).

For the [v2 artifact workflow](../examples/ci/README.md), upgrade the CLI pin, the three
recipe files and the lockfile together. The verifier uses the installed schema and
`ajv@6.15.0`. The workflow uploads available artifacts before enforcing the recorded
result. A clean scan exits 0. Findings and operational failures exit 1. The verifier
uses 2 for missing, malformed or inconsistent artifact sets.

A direct `npm run --silent check:dependencies` can continue to run `depvitals --format json`
with only DepVitals installed. Upgrade any downstream JSON consumer to v2 alongside that pin.

## Compatibility evidence

The [six-root comparison](../compatibility/v0.6.0.md) found two expected changes in unused
devDependencies. Both packages now explain as used by their root `extends` selectors.
Unresolved dispositions from the earlier review remain visible. This comparison used a
development tarball and scoped local measurements. Publication and verification of the
exact release archive are separate.
