# DepVitals

> A simple, lightweight dependency health checker for Node.js projects.

DepVitals is currently under development.

It is inspired by [depcheck](https://github.com/depcheck/depcheck) and aims to provide a modern, focused alternative for checking project dependencies without becoming a large all-in-one analysis tool.

The goal is simple:

- detect unused dependencies;
- detect missing dependencies;
- explain why a dependency is considered used or unused;
- stay fast, lightweight and easy to run.

Planned usage:

```bash
npx depvitals
```

DepVitals is currently in **pre-alpha**. The public CLI and dependency scanner are still being built.
