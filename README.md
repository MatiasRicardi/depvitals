# DepVitals

> A simple, lightweight dependency health checker for Node.js projects.

DepVitals is currently under development.

It is inspired by [depcheck](https://github.com/depcheck/depcheck) and aims to provide a modern,
focused alternative for checking project dependencies, without becoming a large all-in-one analysis
tool.

## Usage

The `v0.0.1` CLI supports:

```bash
npx depvitals
npx depvitals --help
npx depvitals --version
```

## Current status

DepVitals is in early development.

- `v0.0.1` establishes the package and CLI foundation only.
- Dependency scanning is not implemented yet and begins in `v0.1.0`.
